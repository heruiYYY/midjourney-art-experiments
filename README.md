# Midjourney · 美术方向对照实验

33 页交互式课程幻灯片，包含 50 张本地图片、参数、讲解备注及对照实验。

## GitHub Pages 发布

1. 新建仓库，建议命名为 `midjourney-art-experiments`，默认分支使用 `main`。
2. 将本目录内全部文件上传至仓库根目录，包括 `.github/workflows/pages.yml`。
3. 在仓库 Settings → Pages → Build and deployment 中，将 Source 设为 GitHub Actions。
4. 在 Actions 中运行 Publish website，或提交一次修改，等待部署成功。
5. 从 Settings → Pages 查看实际发布网址。

若只需保存源码，可以使用私有仓库并保持 Pages 关闭。公开发布后，网页图片、课程文字和讲解备注均可被访问者查看。

## 使用

- 左右方向键或底部按钮翻页；页码框可跳转。
- M 打开目录，N 打开讲解备注，F 切换全屏。
- 点击图片查看完整原图。
- 网站无需外部 API，也无需原 Sites 登录。
